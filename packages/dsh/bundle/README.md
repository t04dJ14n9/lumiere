# Lumière for DeepSeek Harness

Opens the Markdown notes of a DeepSeek Harness workspace in Lumière's editor,
Obsidian-style Live Preview with wikilinks, embeds, properties, math, Mermaid
and callouts, in DSH's preview sidebar. DSH's own preview stays available from
the viewer menu above the note.

Notes are saved to disk as you type. Built from
[t04dJ14n9/lumiere](https://github.com/t04dJ14n9/lumiere); see
`packages/dsh/README.md` there.
