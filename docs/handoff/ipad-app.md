## Decisions and why

- **`sketch` plugin registration stays in Markdown's catalog** as a thin
  folder, with the format, outlines, service and canvas in `packages/ink`.
  `packages/ink` depending on Markdown's host-service types while Markdown
  imports the plugin would make a package cycle.
- **`force` is stored 0–1** (Pointer Events' scale; PencilKit's force ÷ the
  Pencil's maximum, 4.17), a linear rescale, so no raw information is lost
  and web and iPad strokes compare directly.
- **Points as flat number lists with a `fields` header**, rounded (x, y,
  width 2 decimals; t 4; force, angles, opacity 3): several times smaller
  than objects, and forward compatible.
- **PencilKit data carries a strokes fingerprint**, so an edit made
  elsewhere drops it without Swift having to know.
- **Native plugins in a local Swift package**, not the App target: no
  pbxproj edits per file, and `xcodebuild test` on the package.
- **The on-screen keyboard as a safe-area inset**, not frame resizing:
  one CSS mechanism (`env(safe-area-inset-bottom)`) for the home indicator
  and the keyboard, and no page scroll.
- **iPad only, iOS 17 minimum**: the Notes inks (monoline, fountain pen,
  watercolor, crayon) need iOS 17; iPhone layouts are out of scope.
- **Dev mode loads the Mac's Lumière server** (`LUMIERE_SERVER`), so the
  window, touch work and native plugins can be checked in the simulator
  before host-web exists.
