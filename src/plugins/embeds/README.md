# Embeds

Transcludes full notes, headings and block IDs through resources. A render pass
carries source URI, full text and source-line offset for links, tasks and footnotes.
Cycles and depth over twelve are refused. Local resources remain host-contained;
remote media loads only in trusted workspaces. PDFs and other files are open cards.

Includes the pinned source's image zoom/pan inspector and WebM stream recovery.
Media streams, object URLs, dialogs, styles and nested render passes are owned and
cancelled when the feature or pass stops. Insert Embed has no default binding.
