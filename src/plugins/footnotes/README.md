# Footnotes

Uses the shared metadata registry for numbering, definitions and reference ranges.
Inline references and references inside rendered blocks share keyboard-accessible
hover/focus previews and definition navigation. Definition ranges include multiline
continuations. Insertion chooses an unused label in one native-undoable change.

Injects editor, commands, livePreview and render. Render pre/post processors and
preview passes are owned; turning the plugin off removes its widgets and commands.
